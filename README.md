# Audiophile

Private, responsive storefront experiment adapted from Frontend Mentor's Audiophile e-commerce challenge.

## Product boundary

- Six fictional audio products across headphones, speakers, and earphones.
- The cart persists only in the current browser.
- Checkout validates the complete interaction but never charges, sends, or stores personal information.
- Version 1 has no account, order database, analytics, or live payment provider.

## Local work

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
npm test
npm run lint
```

The project uses Next.js-style App Router source compiled by vinext for Sites. Product imagery and seed copy are challenge assets; see `THIRD_PARTY_ASSETS_LICENSE.md`.
